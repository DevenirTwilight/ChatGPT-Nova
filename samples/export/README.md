These are synthetic examples generated by `tools/export-tests/browser.cjs`, not a real ChatGPT account export. The fixture contains 80 selected-branch messages and another branch which must be excluded.

`conversation.html` and `conversation.md` are committed. The same test also generates `conversation.pdf`, `mobile-light.png`, and `mobile-dark.png`; these generated binaries are available in the CI artifact `export-build-and-samples`.

The PDF sample uses desktop Chromium. Android uses the standard system PrintManager and Save as PDF flow, rendering the same normalized HTML. Desktop PDF evidence does not establish Android PDF correctness or third-party app compatibility.
